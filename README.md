# ✨ AI Spell Check

A **AI writing assistant for Visual Studio Code**.

Improve grammar, spelling, clarity, and tone using AI — directly inside your editor.

---

## 🚀 Features

- 🤖 AI-powered spell correction
- ✍️ Rewrite sentences for fluency
- 💡 One-click **Quick Fix** suggestions
- 🧠 Context-aware improvements
- 🔒 Runs only on **user-selected text**
- ⚡ Lightweight and fast

---

## 🖼 How It Works

1. Select a sentence or paragraph
2. Click the light-bulb 💡
3. Choose **“Improve with AI”**
4. The text is rewritten instantly

---

## 🛠 Installation

1. Open **Visual Studio Code**
2. Go to Extensions (`Ctrl + Shift + X`)
3. Search **AI Spell Check**
4. Click **Install**
